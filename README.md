One funny passive-aggressive note a smart fridge leaves for its owner: **"You opened the door, stared, closed it, opened it again. I have logged 14 visits today and zero decisions. The cheese is judging you too."** The gag runs in three beats: the relatable door-staring ritual, the fridge pulling rank with its own sensor log (fourteen visits, zero decisions), and the sting landing somewhere nobody expects — the cheese has joined in. The program writes this one line to `/output/entry.txt` and nothing else: one line, no extra words, no trailing newline.

## Run it

```sh
node main.ts
```

It makes the output folder when it is missing, writes `/output/entry.txt` as UTF-8 (one line, no trailing newline), then reads the file back to make sure it holds exactly the line above.
